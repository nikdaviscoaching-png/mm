How to shoot

  1. Using Stacker: tap Choose photos, select your shots, wait for the result, tap Save to Photos. Drag the line on the picture to compare with the original.
  2. Tripod + timer. Use a 3 s timer or a remote so nothing moves between shots.
  3. Focus in small steps. Manual focus (Halide, ProCamera or the Camera app's tap-and-hold AE/AF Lock). Step from the nearest edge to the farthest so each shot overlaps the last by ~30–50%. 5 shots is usually enough; up to 10 for deep stones.
  4. Lock exposure for a focus stack (AE/AF Lock). For a light stack, change only the light or the exposure.
  5. Glossy agates: glare is best killed optically — a polarizing filter on the lens plus polarized light at 90° (cross-polarization), or a big diffuser. Light stacking helps when the glare moves between shots.
  6. ProRAW: set Settings › Camera › Formats › ProRAW & Resolution Control → ProRAW Format → JPEG Lossless (Most Compatible). JPEG XL ProRAW can’t be decoded in the browser; Stacker will use its embedded preview instead.
  7. Translucent stones: if the result looks patchy, try See-through in Adjust, or paint fixes with Retouch.
